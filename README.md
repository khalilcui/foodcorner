# Food Corner

Single-page restaurant website built with plain HTML and CSS (no JavaScript, no frameworks).

```
FoodCorner/
├── index.html   page structure, internal CSS, inline CSS
├── style.css    external stylesheet
└── images/      SVG food images, hero and pattern backgrounds
```

Open `index.html` in a browser to view it locally.

## Deploy
- Netlify Drop: drag the whole FoodCorner folder onto https://app.netlify.com/drop
- GitHub Pages: push the folder to a repo, then Settings > Pages > Deploy from branch (main, root)
